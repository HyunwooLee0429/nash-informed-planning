# Nash-informed planning for public-resource coordination

Reference implementation for *Nash-informed Planning for Public-Resource Coordination:
An Application to Aquatic Invasive Species Prevention*
([preprint on SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7484942)).
The framework takes the pure Nash
equilibrium of a decentralized integer programming game (IPG) as the input to a
welfare-improving planning step constrained by individual rationality (IR), and measures the
welfare cost of those participation rationality constraints — the *price of individual rationality* (PIR).
It is instantiated on three game classes — edge-weighted budgeted maximum coverage (EBMC),
the knapsack problem game (KPG), and the kidney-exchange game (KEG) — and applied to a
Minnesota aquatic-invasive-species (AIS) inspection case study.

## Repository layout

```
nash_informed/            core package
  common/                 config, reference-utility construction, Gurobi helpers
  ebmc/  kpg/  keg/        each game class: instances, models, BZR equilibrium search, BSW, pipeline
  <class>/datasets/       benchmark instances
  <class>/results/        precomputed core results
scripts/                  command-line drivers and the map builder
data/                     Minnesota inputs and geospatial layers (see Data and attribution)
```

## Installation

Requires Python 3.10+ and a [Gurobi](https://www.gurobi.com/) license (free for academics)
for the optimization and equilibrium-search steps.

```bash
pip install -r requirements.txt      # or: pip install -e .
```

The interactive-map script needs only `pandas`, `folium`, and `pyproj` (no Gurobi).

## Data and attribution

The Minnesota inputs are used and redistributed here with permission; please retain these
acknowledgments and cite the original providers if you reuse the data.

- **`data/lake_info.csv`, `data/boats1.csv`, `data/Estimation.xlsx`** — the study lakes,
  survey-calibrated lake-to-lake boat-movement estimates, and county inspection-hour /
  budget data, **provided by the Minnesota Aquatic Invasive Species Research Center
  (MAISRC) and the Minnesota Department of Natural Resources (DNR).** The boat-movement
  volumes are survey-based estimates rather than complete direct observations.
- **`data/mn_counties.geojson`** — county boundaries dissolved from the U.S. Census Bureau
  TIGER/Line county-subdivision file for Minnesota (public domain).
- **`data/mn_lakes.geojson`** — lake polygons for the study lakes (keyed by DOW), derived
  from the **Minnesota DNR Hydrography Dataset**
  (https://gisdata.mn.gov/dataset/water-dnr-hydrography), courtesy of the Minnesota DNR.

The raw statewide DNR Hydrography shapefile (~0.6 GB) is **not** included. It is only needed
to regenerate `data/mn_lakes.geojson`; see *Interactive map* below.

## Usage

Run an experiment (results are written under the matching `results/` folder):

```bash
python scripts/run_ebmc_minnesota.py --percentage 50% 75% 100% 125% --include-tailored
python scripts/run_ebmc_random.py
python scripts/run_kpg.py --categories B C
python scripts/run_keg.py
```

Reproduce specific paper results (reuse precomputed inputs; no full re-run):

```bash
python scripts/run_three_rule_pir.py     # PIR under the three reference rules (Minnesota)
python scripts/rerun_kpg_table13.py      # KPG Table 13: warm-start SW with the BSW incumbent
```

## Interactive map

`scripts/make_minnesota_map.py` builds the interactive Minnesota map: county boundaries,
lakes sized by total boat traffic (`w_total` = incoming + outgoing weight), a dot legend,
and one layer per model (NSG, RPNE, BSW, SW, BGC, GC) drawn as the true lake shapes.

```bash
python scripts/make_minnesota_map.py --out mn_lakes_with_grouped_markers.html
```

Both geospatial layers (`mn_counties.geojson`, `mn_lakes.geojson`) are included, so the map
runs out of the box. To regenerate the lake shapes from source, download the DNR Hydrography
open-water polygons (`dnr_hydro_features_all`) from the Minnesota Geospatial Commons and run:

```bash
python scripts/prepare_lake_shapes.py --hydro path/to/dnr_hydro_features_all.shp
```

A prebuilt copy of the interactive map (`mn_lakes_with_grouped_markers.html`) is included in this repository; download it and open it in a browser.

## Precomputed results

A small set of core results is included so the map and the headline tables can be reproduced
without re-running the solver: the per-model lake selections (`all_selected_lakes_100%.pkl`),
the collected PNE sets (`all_PNE_sets_*.pkl`), the per-scenario welfare tables, and the
KPG/KEG/EBMC-random summary CSVs. Everything else is regenerated by the scripts above.
